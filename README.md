# Assignment 3: Graph Algorithms for a Campus Festival

**Course:** Design and Analysis of Algorithms

Implement six graph algorithms: disjoint-set union, Kruskal, Prim, Kosaraju strongly connected components, DFS topological ordering and DAG shortest paths.
